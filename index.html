VR Isle Academy: A VR Digital Twin Approach for Robotic Surgical Skill Development

Achilleas Filippidis, Nikolaos Marmaras, Michael Maravgakis, Alexandra Plexousaki, Manos Kamarianakis, George Papagiannakis

A portable, device-agnostic VR digital twin of a surgical robotic system's simulator, with hand and foot tracking, so trainees can practise robot-control skills without access to expensive, heavy hardware. Errors are assessed both in real time and offline to track performance, and an evaluation with untrained testers showed error metrics dropping significantly as the number of training sessions increased.

PyroLens

PyroLens is a wildfire coordination platform that turns NASA FIRMS satellite fire detections into incidents with PostGIS, forecasts where each fire could spread in the next 1 and 3 hours, and shows it all on a live dispatcher map.

  • .NET 9 worker service ingesting MODIS and VIIRS detections every 10 minutes with idempotent batch writes (INSERT … ON CONFLICT DO NOTHING)
  • incident clustering in PostGIS: nearest-incident attach, then ST_ClusterDBSCAN in the Greek Grid projection, under a PostgreSQL advisory lock
  • weather from Open-Meteo, McArthur Mk5 fire danger index, and +1 h / +3 h spread ellipses stored as PostGIS polygons and served as GeoJSON
  • ASP.NET Core REST API with health checks, serving a React + TypeScript Leaflet map
  • xUnit unit tests, Testcontainers integration tests against real PostGIS, Vitest for the map, and GitHub Actions CI building the Docker images

VLab Orchestrator

VLab Orchestrator is a Unity research-software framework that applies one session, shared-access, authority-transfer, synchronisation, telemetry and evaluation model across five multiplayer networking backends, so they can be benchmarked against the same reproducible protocol. The accompanying paper is submitted to IEEE Access.

  • SDK-independent core package (FCFS request queue, state models, configuration, benchmark settings) distributed through Unity Package Manager
  • project-authored adapters for Photon PUN 2, Photon Fusion, Netcode for GameObjects, FishNet and Mirror
  • editor setup window that verifies pinned SDK versions and materialises the five-backend runtime reproducibly
  • deterministic benchmark scenarios, CSV export, and edit-mode tests
  • released under MIT and archived on Zenodo with a DOI, plus a Code Ocean analysis capsule
  • C#
  • Unity
  • Multiplayer networking
  • Benchmarking
  • Research software
